# Salar de Uyuni · Sky Mirror · 天空之镜

A standalone, interactive 3D Salar de Uyuni you can open in the browser.

**Live:** https://huagechen-lab.github.io/salar-de-uyuni/

## Controls

- Arrow keys move the camera (forward / back / strafe); works from the landing page too
- Drag to orbit, scroll / pinch to zoom
- Double-click to reset the camera
- Time presets: Day / Sunset / Night
- Weather presets: Clear / Scattered / Overcast / Light rain / Storm
- God view: pauses auto-orbit, then returns to the exact camera position
- Auto-orbit toggle
- Chinese / English UI: auto-detected from the browser, toggle in the top bar; `?lang=zh` / `?lang=en` override. The landing UI and the embedded scene HUD switch together.

## What it is

A single-file Three.js scene generated end-to-end by an LLM from one prompt:
flat salt crust under a thin sheet of water, mirrored sky, distant Andes and
cactus islands, with a 3 x 5 time/weather system. No backend, no tracking, no
external assets beyond the Three.js CDN.
